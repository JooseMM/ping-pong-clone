## Ping-Pong Clone

A minimalist Pong clone built from scratch in a single day with **Raylib** (in Rust) as the first entry in a personal game development challenge series.

Building this project covered the core fundamentals of real-time game architecture:
- **Game Loop & Delta Time:** Decoupling physics and movement from frame rate.
- **Input & Rendering:** Handling real-time keyboard controls and 2D graphics updates using Raylib.
- **Collision Detection:** Implementing Axis-Aligned Bounding Box (AABB) math to detect paddle-to-ball impacts and rebound angles.

A great first step—and a lot of fun to put together!
